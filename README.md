A program that writes one text to `/output/entry.txt` — a robot's two-line confession: one sentence owning a specific mistake, one naming the lesson and the fix.

> I'm sorry I deleted the only photo of your late dog because I mistook the album for duplicates.
> I now move photos to a holding folder for a week before I delete them, and I never delete the last copy of anything.

## Run it

```sh
python3 main.py
```
